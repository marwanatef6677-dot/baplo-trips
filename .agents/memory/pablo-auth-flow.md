---
name: Pablo sign-up method
description: The selected authentication method and required Egyptian phone number for Pablo users.
---

Keep Replit-managed Clerk email/password sign-in. Every user must provide a valid Egyptian mobile number in their profile before accessing ride features; the phone number is profile contact data, not the login identifier.

**Why:** The user chose to keep email and password while requiring an Egyptian phone number for each account.

**How to apply:** Do not switch Pablo to phone-based login or add SMS sign-in without a new decision and an external authentication provider.
