---
name: Pablo location selection
description: Customer pickup and destination selection preferences.
---

Customers must be able to search for pickup and destination by place name, select a point on the map manually, and type or edit a readable address themselves. A map pin alone should not replace the human-readable address.

**Why:** The owner explicitly requested both name search and manual map selection, then clarified that typed addresses must remain available.

**How to apply:** Keep all three methods available for both pickup and destination; choosing a search result may fill the editable address field, while a manual pin still needs a readable address.
